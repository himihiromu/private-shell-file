# private-shell-file

個人用の shell script / セットアップ断片を一時的に整理するためのリポジトリです。

## 現在の位置づけ

このリポジトリは、恒久的な dotfiles 管理の完成形というより、**環境構築や端末ごとの差分を整理するための中継地点**として扱います。

現時点では以下のような内容を置く想定です。

- OS / 端末ごとのセットアップ用スクリプト
- 一度きり、または低頻度で使う環境構築メモ
- dotfiles へ移す前に試行錯誤した設定断片
- まだ配置先が固まっていない個人用 shell script

## 将来的な方針

長期的には、継続的に管理したい設定や再利用性の高い構成は `dotfiles` リポジトリへ寄せていく想定です。

特に以下に当てはまるものは、段階的に `dotfiles` へ統合していきます。

- 恒久的に使うシェル設定
- 端末をまたいで再利用したい設定
- chezmoi で管理したい設定ファイル
- テンプレート化や OS 別分岐に向いている設定

## このリポジトリに残すもの

当面は、次のようなものをこのリポジトリ側で扱います。

- まだ整理途中のセットアップ手順
- 一時的な検証用スクリプト
- どの管理先が適切か未確定な設定断片
- `dotfiles` に入れる前に内容を見直したいもの

## 境界の考え方

### `private-shell-file` 向き
- 一時的・検証中のもの
- 端末固有で再利用性が低いもの
- まだ役割が固まっていないもの

### `dotfiles` 向き
- 長期的に維持するもの
- 複数環境で再利用したいもの
- ルール化しやすい設定
- chezmoi で管理しやすいもの

## 補足

このリポジトリは、将来 `dotfiles` に統合するための棚卸し場所としての性格も持ちます。
そのため、今後はブランチごとの内容やファイル種別を見ながら、段階的に移行方針を整理していく前提です。
